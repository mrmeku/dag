# Contributing

This repository is a read-only export. Every commit on `main` is made by an export job from the
upstream source, and the `v*` tags are made by the release. Nothing is merged here, so pull
requests are closed automatically with a pointer to this file.

Bug reports and feature requests go in [issues](https://github.com/mrmeku/dag/issues). If you have
a fix, attach it to an issue as a patch or a link to a branch on your fork; it is applied upstream
and arrives here with the next export, with credit in the release notes.
